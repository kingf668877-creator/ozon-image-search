# 搜索进度与 Excel 导出设计

日期：2026-08-16
范围：只增加下载/图搜双进度，以及将现有 JSON 导出替换为 Excel 表格导出。现有上传、下载、图搜、并发、结果展示和任务流程保持不变。

## 需求边界

本次只改两个用户可见功能：

1. 进度区域增加两个独立进度：下载图片进度、图搜图片进度。
2. 将“导出 JSON”改为“导出 Excel 表格”。

不修改现有下载重试策略、图搜并发策略、任务状态机、结果排序、上传方式和已有结果字段。

## 双进度

- 下载进度显示 `downloaded_count / total_images`。
- 图搜进度显示 `searched_count / total_images`，其中已完成、失败、无结果都视为该图片的图搜处理已结束。
- 两个进度独立更新，下载继续时图搜进度可以落后，图搜处理也可以在下载达到启动阈值后提前增长。
- 现有总进度和状态文案保留，不改变任务完成判断。
- 当后端字段暂时缺失时，前端使用现有总进度作为兜底，不显示错误数据。

## Excel 导出

- 原有“导出 JSON”按钮改名为“导出 Excel”。
- 点击按钮继续使用当前任务结果，不改变结果查询接口和任务数据结构。
- 导出文件为 `.xlsx`，每张上传图片占一行。
- 表格固定三列：
  - `上传图片`：第一列嵌入原始上传图片；无法读取时保留图片名称。
  - `商品链接`：该图片图搜结果中匹配度最高商品的完整商品链接。
  - `商品主图链接`：同一最佳匹配商品的主图完整 URL。
- 没有结果、图搜失败或图片下载失败时仍保留该图片行，缺失字段留空；不改变已有结果展示。
- 不增加商品名称、价格、评分等其他列。
- 表格使用固定列宽、合理行高、首行表头和浅色交替行样式；图片按单元格范围缩放。

## 实现约束

- 优先复用现有任务状态接口和结果数据，不新增并行任务流程。
- 服务端只增加 Excel 文件生成和下载路由；前端只增加双进度展示和导出按钮调用。
- Excel 生成依赖使用项目已有依赖或新增一个明确的表格库；不修改现有图搜请求逻辑。
- 导出失败时沿用现有错误提示模式，不影响任务结果。

## 验收

- 下载和图搜进度在同一任务中独立显示并随轮询更新。
- 现有总进度、任务完成状态和搜索结果无回归。
- 点击导出后下载 `.xlsx` 文件而不是 `.json`。
- Excel 第一列包含上传图片，第二列是最佳匹配商品链接，第三列是该商品主图链接。
- 每张上传图片都有一行；无结果图片不会被静默丢弃。
- 原有功能和运行策略不发生额外变化。
